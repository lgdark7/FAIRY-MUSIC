## Overview

**FAIRY MUSIC** is a high-performance, modern Android music streaming application designed for seamless listening, background playback, and synchronized lyrics — powered by a lightweight native audio engine.

---

## Key Features

- **Ad-Free Streaming** — Pure, uninterrupted high-quality music streaming.
- **Synchronized Lyrics** — Real-time synced lyrics with syllable/word highlighting and dynamic animations.
- **Offline Playback & Downloads** — Save your favorite tracks, albums, and playlists for offline listening.
- **Seamless Background Playback** — Uninterrupted listening with screen off or while multitasking.
- **Listen Together** — Real-time multi-user synchronized listening sessions with zero drift.
- **Spotify Sync** — Import and mirror your favorite Spotify playlists with a single tap.
- **Audio Equalizer & Sound Effects** — Customizable EQ profiles, bass booster, and surround audio rendering.
