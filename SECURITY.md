# Security Policy

## Supported Versions

We release patches for security vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in FAIRY MUSIC, please report it responsibly:

1. **Do NOT** create a public GitHub issue
2. Reach out via GitHub Security Advisory on [https://github.com/lgdark7/FAIRY-MUSIC](https://github.com/lgdark7/FAIRY-MUSIC)
3. Or contact developer directly on Instagram: [https://www.instagram.com/lg_dark_7](https://www.instagram.com/lg_dark_7)
4. Include steps to reproduce, impact, and suggested mitigations.

## Sensitive Information

The following files contain sensitive information and should never be committed:

- `local.properties` - Local development configuration
- `*.keystore` / `*.jks` - App signing keys
- `secrets.properties` - API keys and secrets

## Data Privacy

FAIRY MUSIC is committed to user privacy:

- **No telemetry/data harvesting**: User data stays 100% locally on device
- **Open source**: Full codebase available for inspection and audit

Thank you for helping keep FAIRY MUSIC secure!
